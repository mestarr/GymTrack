# GymTrack-Upravljanje-lanovima-teretane-i-pra-enje-napretka-
GymTrack - Aplikacija za upravljanje članovima Teretane i praćenje napretka treninga u teretani.  Aplikacija omogućuje vlasniku teretane vođenje evidencije članova i njihovih treninga.  Implementirane su potpune CRUD operacije, filtriranje po datumu i vrsti vježbe,  automatski izračun statistika te vizualizacije pomoću Chart.js.
