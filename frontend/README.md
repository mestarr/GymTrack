# Frontend - GymTrack

Staticki frontend serviran preko nginx kontejnera.

## Datoteke

- `index.html` - glavna stranica sa sekcijama su: Pocetna, Clanovi, Treningi, Statistike.
- `style.css` - osnovni stil: Bootstrap + vlastiti CSS.
- `fetchData.js` - fetch pozivi prema backendu na port-u 5000
- `displayData.js` - prikaz listi, paginacija, poruke.
- `pageHandling.js` - prebacivanje izmedju sekcija
- `formHandling.js` - forme za clana i trening
- `filterHandling.js` - filtriranje treninga
- `chartHandling.js` - bar, line i pie graf.
